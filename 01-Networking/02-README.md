### Network Media

​## Ever wondered how data actually travels across the internet? It all comes down to Network Media—the physical or wireless channels that connect devices.

​## Here is a quick breakdown of the three main types:

​### Guided Media (Wired)

​### Copper Cable (UTP/STP): Transmits data using electrical pulses. Cost-effective and widely used in local networks (LANs).

​### Fiber-Optic Cable: Uses light pulses to transfer data through glass/plastic strands. Ultra-fast, high bandwidth, and immune to electromagnetic interference (EMI).

​### Unguided Media (Wireless)

​### Radio Waves / Wi-Fi / Cellular: Transmits data through the air via electromagnetic signals. Offers high mobility and easy deployment.
